# ContainerGroupTcpProbe

Configuration for a TCP probe used to check container health via network connectivity.

**Properties**

| Name | Type | Required | Description                                                                                            |
| :--- | :--- | :------- | :----------------------------------------------------------------------------------------------------- |
| port | int  | ✅       | The TCP port number that the probe should connect to. Must be a valid port number between 0 and 65535. |
