# DatadogTagForContainerLogging

Represents a Datadog tag used for container logging metadata.

**Properties**

| Name  | Type | Required | Description                    |
| :---- | :--- | :------- | :----------------------------- |
| name  | str  | ✅       | The name of the metadata tag.  |
| value | str  | ✅       | The value of the metadata tag. |
