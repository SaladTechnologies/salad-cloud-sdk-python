# InferenceEndpointJobEvent

Represents an event for inference endpoint job

**Properties**

| Name   | Type                            | Required | Description                                              |
| :----- | :------------------------------ | :------- | :------------------------------------------------------- |
| action | InferenceEndpointJobEventAction | ✅       | The action that was taken on the inference endpoint job. |
| time   | str                             | ✅       | The time the event occurred.                             |
