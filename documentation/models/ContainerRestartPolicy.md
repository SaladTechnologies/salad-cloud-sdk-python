# ContainerRestartPolicy

Specifies the policy for restarting containers when they exit or fail.

**Properties**

| Name      | Type | Required | Description  |
| :-------- | :--- | :------- | :----------- |
| ALWAYS    | str  | ✅       | "always"     |
| ONFAILURE | str  | ✅       | "on_failure" |
| NEVER     | str  | ✅       | "never"      |
